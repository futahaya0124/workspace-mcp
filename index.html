workspace-mcp

workspace-mcp は、開発者本人が自分の Google カレンダーに予定を書き込むための個人用ツールです。一般向けには提供していません。

プライバシーポリシー

  • 取得する情報: 本人の Google カレンダーの予定（Google の同意画面で許可された範囲のみ）。
  • 使い道: 本人のカレンダーへの予定の追加・更新・削除と、本人のPC内での予定の参照だけに使います。
  • 第三者提供: 取得した情報を第三者に提供・販売することはありません。
  • 保存: 認証情報は本人のPC内にのみ保存し、外部サーバーには送りません。
  • Google API から受け取った情報の利用は、Google API Services User Data Policy（Limited Use 要件を含む）に従います。

制定: 2026年10月24日
